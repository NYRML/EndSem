# AI Driven Full Stack HR System

This project is a comprehensive Full Stack MERN application integrated with Advanced AI (OpenRouter) to provide intelligent workforce management, promotion predictions, and training recommendations. 

This repository was developed for the **AI Driven Full Stack Development (AI308B) ESE Examination**.

## 🚀 Features

- **MERN Stack Architecture**: Built with MongoDB, Express.js, React, and Node.js.
- **AI Recommendation Engine**: Generates dynamic promotion insights, employee rankings, and personalized training feedback.
- **Secure Authentication**: Implements JWT token-based authentication and bcrypt password hashing.
- **Premium User Interface**: Features a beautiful glassmorphism design with dynamic color gradients and smooth micro-animations.
- **Real-time Search & Filtering**: Instantly search employees by name or department.

## 📁 Repository Structure

- `/backend`: Contains the Node.js/Express server, MongoDB Models, Controllers, Middleware, and API routes.
- `/frontend`: Contains the Vite/React application, CSS styling, API config, and UI components.
- `Report.md`: Contains the final examination report with code output screenshots and live deployment links.

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Vanilla CSS, Lucide Icons, Axios.
- **Backend**: Node.js, Express.js, Mongoose, JWT, bcrypt.
- **Database**: MongoDB Atlas.
- **AI Integration**: OpenRouter API (Fallback supported).

## 🏃‍♂️ Running Locally

1. **Clone the repository**:
   ```bash
   git clone <your-repo-link>
   cd endsem
   ```

2. **Start Backend**:
   ```bash
   cd backend
   npm install
   node server.js
   ```

3. **Start Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
